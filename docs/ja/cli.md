# CLI

| コマンド | 役割 |
|---------|------|
| `doctor [--ping]` | 設定 / LLM 確認 |
| `formats` / `detect` / `analyze` | 形式 |
| `profile …` | カスタムプロファイル |
| `init` / `extract` / `translate` / `writeback` / `run` | 本流 |
| `status` / `export-jsonl` / `import-jsonl` | 状態・交換 |
| `learn …` / `glossary …` | 経験・用語 |

グローバル：`--config`、`--client`。
